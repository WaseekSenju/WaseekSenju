## 🧠 Philosophy

> **In the LLM era, anyone can write syntax. The engineers who matter are the ones who can design the system around it.**

I'm a Software Engineer with a Computer Science foundation who cares about **architecture, tradeoffs, and scale** — the things that separate a working prototype from a system that survives contact with real users. I build across **mobile, web, and ML**, and I bring the same lens to all of it: *what breaks, what scales, and why.*

<table>
<tr>
<td width="50%" valign="top">

### 🏗️ How I Think
- **Design before code** — data models and API contracts before implementation
- **Tradeoffs, not templates** — consistency vs. availability, simplicity vs. flexibility
- **Debug the system, not the symptom** — root cause over quick patch
- **AI as leverage, not a crutch** — I use it to move faster, not to skip understanding

</td>
<td width="50%" valign="top">

### ⚡ What I Ship
- Cross-platform apps in **Flutter** — from architecture to app store
- Backend systems in **Ruby on Rails** — APIs designed around real usage
- ML pipelines in **Python** — from raw data to trained model
- Systems-level code in **C/C++** — parallelized with OpenMP, MPI, CUDA

</td>
</tr>
